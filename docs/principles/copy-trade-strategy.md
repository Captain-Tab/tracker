## 一、核心思维（5 条心智模型）

| # | 心智模型 | 一句话 |
|---|----------|--------|
| 1 | **跟单是「选人」游戏，不是「操作」游戏** | 80% 的成败在你按下「跟谁」那一刻就定了。执行再完美，跟错人也是亏。这就是 discovery 比执行腿值钱的原因。 |
| 2 | **你永远跑输你跟的人** | 延迟+滑点+funding 是物理天花板（不可消除）。你的目标不是「赚得和他一样多」，而是「他赚的足够多，刮掉一层我还有得赚」。 |
| 3 | **跟单跟的是「持仓状态」，不是「动作」** | 关心他**现在持有什么**，不关心他成交了几笔。这样断线/漏单/重启都能自愈（净仓位收敛）。 |
| 4 | **频率不是你选的，是目标替你选的** | 你跟低频手你就是低频，跟高频手你就是高频。所以「选什么频率」= 在选人阶段就决定了，不是执行阶段的旋钮。 |
| 5 | **少亏比多赚重要** | discovery 权重最高的是盈亏比/恢复比（控亏质量），不是收益。能活下来的跟单者，靠的是不爆，不是抓大。 |

## 二、核心逻辑链与可操作原则

### 核心逻辑链（整个体系的骨架）

```
选 edge 厚的低频人（扛得住天花板）
   → 按净仓位收敛对齐（保证仓位对、能自愈）
   → 完全跟随其进场与离场（不做单笔自主择时）
   → 每笔带滑点保护 + 追高放弃闸（保证不坏价进场）
   → 风控放在「目标级 + 账户级」（仓位封顶 / 目标熔断 / 全局急停）
   → 用 Agent Wallet 执行（保证被黑也提不走钱）
   → 人留在回路里做急停（保证失控能止损）
```

### 可操作原则（按优先级）

1. **只跟 edge 厚到能扛延迟+滑点+funding 的人** —— 低频精准 > 高频薄利。这是第一性的。
2. **仓位对齐用收敛，不用复制** —— 永远朝「目标当前净仓位」纠偏，错一次下一轮自愈。
3. **完全跟随，不做单笔自主择时** —— 不止盈、不止损、不移动止损。离场跟着目标走，因为「何时离场」是你租用的判断里最值钱的部分（推导见 §6）。
4. **每笔都设保护价，追太远就放弃** —— 宁可错过，不可坏价成交。少赚 ≠ 亏，坏价 = 真亏。
5. **风控在目标级，不在单笔级** —— 仓位占比封顶 + 目标熔断（整体破位就停跟并平掉跟他的仓）+ 全局 `/flatten` 急停。这三者都与收敛兼容（见 §6.3）。
6. **不押单点** —— 分散到 5–10 个目标 / 多币种，对齐 discovery 的 `maxDayShare≤0.7` 思想。任何一个目标爆掉不能伤筋动骨。分散有执行前置（N:1 净额收敛，见 §7）。
7. **私钥不上服务器，急停先于自动** —— Agent Wallet + `/flatten`，安全永远先于收益（见 blueprint §10.7、server-architecture §8）。
8. **定期对账 + 定期换人** —— 标的会过气（discovery 每周刷新的原因），跟单不是「设好就不管」。

## 三、三个易混概念（原则的支撑）

### 3.1 结构性天花板：为什么跟单注定跑输目标

你不是和目标同时下单，而是在他成交**之后**才动手，中间有三层固定损耗：

- **延迟**：目标成交 → 推 fill → 你收到 → 算单 → 下单撮合。全自动也有几百 ms 到几秒，价格已动。
- **滑点**：你下单时价已不是他的成交价，通常往不利方向跑（他买完价被推高，你接更高的价）。
- **funding/手续费**：低频长持时，资金费率与手续费**不等比镜像**目标（你延迟进场、费率档/持仓周期不同）。这层也要计入「刮掉的那一层」，别假设它中性。

**例**：目标 $100,000 开多，等你跟进价已 $100,050（+5bp）。他赚 +50bp 平，你只拿 +45bp，再扣 funding/手续费。**每笔被刮一层。**

**结论**：高频手单笔 edge 薄（10–20bp），刮掉就没了；低频手 edge 厚（几百 bp），刮十几 bp 无伤。这是物理上限，**只能靠「选 edge 厚的人」对冲，不能靠技术消除**（对应 blueprint §9.1）。

### 3.2 净仓位收敛 vs 逐 fill 复制

| | 逐 fill 复制（错） | 净仓位收敛（对） |
|--|-------------------|------------------|
| 思路 | 他成交一笔，我镜像一笔 | 只对齐「他现在净持有多少」vs「我现在多少」，补平差额 |
| 漏单 | 永久少一块，补不回 | 下一轮发现差额自动补 |
| 重启 | 不知跟到哪，重复或漏 | 拉一次真实仓位重算即对齐，本地记录全丢也不怕 |
| 误差 | 只增不减，不自愈 | 每轮朝正确答案纠偏，幂等自愈 |

一句话：逐 fill 是「复制动作」（错一次永久偏），收敛是「对齐结果」（每轮纠偏）。这是合格与否的分水岭（blueprint §10.4）。

> **重要澄清**：收敛保证「仓位方向/规模对得上 + 能自愈」，**不保证成交价和目标一样**。价格差属于 §3.1 的天花板，独立存在，靠「选人 + 追高放弃闸（`MAX_CHASE_BPS`）」控制，不靠收敛。
>
> **收敛的幂等性只对「无状态」成立**：一旦在跟单者侧引入任何「链上查不到、只能本地累计」的状态（如移动止损的历史高点 peak），重启就丢失、幂等性破裂。这是 §6 否决单笔自主择时的工程理由之一。

### 3.3 IOC 零成交是保护生效，不是失败

**IOC（Immediate-Or-Cancel，立即成交否则取消）**：带保护价下单，能立刻成交的成交，剩余当场撤销、不挂单。

- 触发「零成交」= 价格已冲破你的保护价 = 市场跑远了，现在追进去就是**追高接盘**。
- 此时「不成交」好过「坏价成交」：不成交最多**少赚**（仓位下一轮还能补）；坏价成交是进场价太烂，**真亏**。
- **少赚 vs 真亏，选少赚** —— 这就是「宁可错过，不可坏价成交」。

**边界**：「没成交好过成交」只在价格冲破保护价时成立，平时该成交照样立即成交。若**天天大量零成交**，是保护价设太紧（参数问题），该放宽 `MAX_SLIPPAGE_BPS`。

> **诚实承认的盲区**：右尾大赢家常伴随**单边急行情**，价格持续冲破保护价 → 你可能**轮轮零成交、错过这一波的进场**。这是天花板的一种体现，不是 bug。处理方式是接受它（这波 miss 掉），由收敛在价格回到保护带内时下轮补；**绝不为了不 miss 而取消滑点保护去追高**。选 edge 厚的人正是为了让「偶尔 miss 一波」不致命。

## 四、跟单 vs 信号跟随：一条不能混的边界

这是本文最重要的一条边界，文档此前的病灶就是把这两件事混成了一件：

| | 你信任谁的判断 | 它是什么 | 适配的执行机制 |
|--|--------------|---------|---------------|
| **跟单** | 完整信任目标（进场 + 离场都跟） | 收敛镜像，无状态，幂等 | 净仓位收敛（blueprint §10.4） |
| **信号跟随** | 只借他进场，离场你自己来 | 一套**独立的择时策略** | 你自己的有状态择时系统 |

**核心论点**：跟单的本质是**租用别人的判断**，而「何时离场」是一个交易者判断里**最值钱的部分**。你若在单笔上用止盈/移动止损覆盖他的离场，等于宣称「我的离场判断比他好」——但**如果你的离场判断真的更好，你为什么还要跟他？** 这在逻辑上自相矛盾。

所以「用他的信号 + 自己止盈」**不是跟单，是信号跟随**。它是另一个产品，有自己的逻辑、状态管理和风险，**不要塞进跟单的叙事里**。

> 之后若要发展「自己的下单逻辑 / 自主择时」，那属于**信号跟随或自营策略**这条独立路线，单独立项评估，不在本文（纯跟单）范围内。

## 五、策略选择：高频薄利 vs 低频厚利

「多单·小额·赚 10 点就跑」vs「少操作·大额·厚利」——先纠正：**频率由目标决定，不由你**；金额是独立的仓位管理维度；「赚 10 点就跑」是 §4 的信号跟随，不是跟单。真正能比的是跟**高频薄利手** vs 跟**低频厚利手**：

| 维度 | 跟高频手（多单·薄利） | 跟低频手（少操作·厚利） |
|------|----------------------|------------------------|
| 最终收益 | ❌ edge 被延迟+滑点+funding 吃光甚至倒亏 | ✅ 单笔厚利，刮一层仍有得赚 |
| 稳定性 | ❌ 单多 → 误差累积，方差大 | ✅ 单少 → 每笔可仔细对账保护 |
| 可靠性 | ❌ 对延迟极敏感，抖一下就跟丢 | ✅ 对延迟不敏感，几秒无所谓 |
| 执行可实现性 | ❌ 要低延迟/抗限流/高并发，成本陡增 | ✅ 现有 Node + 共享限流即可 |
| 可复制性 | ❌ edge 来自速度/做市，复制不了 | ✅ edge 来自判断，可被镜像 |

**结论**：跟单语境下「低频厚利」全维占优。`discovery` 专设低频精准通道（PF≥3、胜率≥70%），正是指向这条路。

> **限定**：「全维占优」限定在「跟单」语境（完整复制进出场）。它**不依赖**目标是趋势型还是均值回归型——因为纯跟随对两种类型都正确（你完整复制他的离场）。目标的趋势/均值回归标签只用于**选人与资金分配**（见 §6.4），不用于离场。

## 六、离场与风控：为什么纯跟随 + 目标级风控

### 6.1 被否决的方案：固定止盈与移动止损

- **固定止盈（如 10%）**：趋势型目标的 alpha 多在「右尾」（少数大赢家），固定止盈把右尾一刀砍平——他赚 50% 你 10% 就跑，主动放弃 40%，把高手削成平庸账户；只止盈不止损还是「赚小亏大」的爆仓结构。**否决。**
- **移动止损**：看似比固定止盈聪明（保右尾），但有两个致命问题：
  1. **与收敛机制级对冲**：你移动止损平掉 BTC → 你仓位归零 → 目标仍持有 → 下一轮收敛 `delta = desired − 0` **立刻把你刚止损的仓以更差的价买回来**。
  2. **它的 peak（历史高点）是链上查不到的本地状态**，进程重启即丢，**直接破坏 blueprint §10.4「重启全量重算即安全」的幂等性**。
  3. **它对均值回归型高手有害**：discovery 选出的高胜率（≥70%）目标盈利集中在密集小赢、不在右尾，「让利润奔跑」反而误杀他的右侧出场点。

  **否决。** 移动止损会把系统从「无状态幂等收敛」颠覆成「有状态择时系统」，是整套理念里风险最高、收益最不确定的一步。

### 6.2 采纳的方案：完全跟随，不做任何单笔自主择时

理由见 §4：离场是你租用的判断里最值钱的部分，自己覆盖它逻辑不自洽。**纯跟随对趋势型和均值回归型都正确**，且让系统回归无状态幂等收敛的干净核心——§6.1 的两个矛盾从源头消失，不需要打补丁。

### 6.3 风控粒度上移到「目标级 / 账户级」

不做单笔止损 ≠ 没风控。关键洞察：**风控的粒度应该是「目标」，不是「单笔」。** 目标级风控天然和收敛兼容——它只是「合法地变更收敛目标」，不绕过、不对冲收敛：

| 层 | 机制 | 为什么和收敛兼容 |
|----|------|------------------|
| **1 选人** | 信任 discovery 的 PF/RF 控亏质量 + 每周刷新 | 你信的就是他不爆——第一道也是最重要的风控 |
| **2 仓位封顶** | 单目标 `desired` 占净值上限（`MAX_POSITION_SIZE_PERCENT`） | 限制单点敞口，不碰择时 |
| **3 目标熔断** | 目标**整体**回撤/破位超阈值 → 把该目标 `desired` 整体归 0、平掉跟他的仓、停跟 | **`desired→0` 是合法的收敛目标变更**，收敛照常执行、幂等安全；判定用**目标的累计表现**（watch 已在算），可从链上+目标数据重建，**不引入 peak 那种不可重建本地状态** |
| **4 全局急停** | `/flatten` 一键平所有仓（人工或自动触发） | architecture §8 已有 |

**第 3 层与被否的移动止损的本质区别**：移动止损是「我自己仓位的 peak 触发平仓」（链下状态、与收敛对冲）；目标熔断是「这个人整体不行了，不跟他了」（目标数据驱动、是收敛目标的合法归零）。前者撕裂系统，后者完全自洽。

### 6.4 目标类型标签的正确用途

discovery 已能算 `avgHoldMin`/PF/胜率。这些标签**只用于「跟不跟他、给他分多少钱」**（如对高方差趋势型分配更少资金、对稳定均值回归型分配更多），**不用于决定离场**（离场一律纯跟随）。

## 七、最终方案推荐

### 7.1 一句话方案

> **对每个目标完全跟随（不自主择时）+ 单目标资本占比封顶 + 目标级熔断 + 全局急停 + 分散到多个低频目标。** 风控全部放在目标/账户级，系统保持无状态幂等收敛的干净核心。

### 7.2 执行层缺口与对齐（落地前必须补）

strategy 主张要有 blueprint 的实现支撑，以下是当前缺口：

| 缺口 | 现状 | 落地前必须补 |
|------|------|-------------|
| **分散多目标** | blueprint §10.3 当前只有 1:1 单目标收敛 | 升级到 **N:1 净额收敛**：`desired[coin] = Σ_t ratio_t × targetNet_t[coin]`，多目标对同币多空自动净额。**没有这一步不准上多目标。** |
| **目标爆仓/被套** | 仅靠人工 `/flatten` 兜底 | 目标熔断（§6.3 第 3 层）+ 接受「目标爆仓 = 一个被动离场信号」，纯跟随照常处理 |
| **杠杆爆仓点不对齐** | blueprint §3.4 复制杠杆数字 | 改用**保证金率约束**（本地维持保证金距离 ≥ 目标的距离）+ 单目标敞口子账户隔离，使你不先于目标爆仓 |
| **funding 侵蚀** | discovery 已能算目标 funding | 计入 §3.1「刮一层」的跟单净收益核算，不假设等比镜像 |

### 7.3 延迟 vs 确认：二选一，不要都要

- 半自动「人点 ✅ 才下单」引入**分钟级**延迟，比天花板担心的「几秒」高 1–2 个数量级，二次侵蚀 alpha；且 pending 状态机崩溃恢复是坑。
- **起步就纯自动 + 人工 `/flatten` 急停**（信任 discovery 选人到愿意自动跟，就不该每单再要人确认）。
- 半自动「推按钮确认」作为**独立的信号产品**另算，**不挂「低延迟跟单」的叙事**。

### 7.4 落地节奏

| 阶段 | 做法 | 性质 |
|------|------|------|
| **1 纯 B** | 单目标 · 完全跟随收敛 · 仓位封顶 · `/flatten` · 自动执行 | 最干净，幂等无状态，DRY_RUN 可验 |
| **2 目标熔断** | 加目标级回撤熔断（`desired→0` 式，幂等安全） | 仍无破坏性本地状态 |
| **3 N:1 分散** | 补净额收敛公式，扩多目标 + 子账户隔离敞口 | 收敛幂等性保住 |
| **~~移动止损 / 固定止盈~~** | **删除**——单笔自主择时不属于跟单（见 §4、§6.1） | 不做 |
| **（独立产品）信号系统** | 借进场信号 + 自主离场 + TG 确认，单独立项 | 不属于跟单 |

### 7.5 总收

**跟单的纪律不是「我什么时候离场」，而是「我跟不跟这个人、给他多少钱、他什么时候该被我踢掉」。** 把风控从单笔择时上移到目标层，系统就回到无状态幂等收敛的干净核心——这比给移动止损打补丁更彻底，也更符合跟单的第一性原理。
