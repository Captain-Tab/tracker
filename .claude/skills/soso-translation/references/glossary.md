# 术语词汇表 Glossary

> 项目专属译法。翻译时优先查此表，确保同一术语在所有 key 中译法一致。
> 新增术语按下方格式追加即可。

---

## 使用方式

翻译前先检查：目标词是否在此表中有规定译法。
有 → 直接使用规定译法，不自行发挥。
无 → 按语境翻译，并考虑是否需要补充到此表。

## 如何添加新术语

在对应分类末尾追加一行：

```
| 英文术语 | 中文译法 | 繁中译法 | 日语译法 | 韩语译法 |
```

如需要支持更多语言（es/ru/vi/tr/fr/de），在表头加列即可。
