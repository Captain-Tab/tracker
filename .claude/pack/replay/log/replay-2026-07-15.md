### 认知纠正

1. **结果论陷阱**：不能因为「如果持有就赚了」来反推决策对错。正确问法：**开仓时有止损点吗？没到止损为什么平？** 问题不在平得太早/晚，在根本没有「止损点」这个东西。

2. **止损是保费，不是错误**：被洗=止损位的成本，不是错误。真正错误=没有止损位，让一笔单子从 +$265 走到 −$50。止损位≠固定%，止损位=**结构失效点**（支撑破/阻力破=你的逻辑错了）。

3. **持有 vs 扛单只差一个失效点**：ETH 扛到 −40%，是因为没有事先定义「什么情况下我的做多逻辑是错的」。没有失效点就割=在任何随机情绪时刻割=期望值为负。

4. **跟单的离场是目标最值钱的判断**：你花钱（跟单费或跟随成本）买的就是对方的离场判断。跟了进场但不跟离场=花了钱只拿了别人能力的一半，自己恐慌离场=用你最差的能力替换他最好的能力。

### 重复模式（致命 3 连）

```
浮盈出现 → 不止盈（贪）
  → 价格反向 → 恐慌 → 割在情绪峰值
    → 价格恢复原方向 → 懊悔 → 报复性追单（7/15 ETH 三连）
      → 继续亏损
```

**一句话病根**：没有「开仓前写死的离场规则」，每次离场都是情绪在极端时刻做的随机决策。

## ④ 建议

### 思维层（规则建设）

1. **没止损不开仓**。开仓前写死两样：① 止损价（结构位，不是固定%）② 止盈逻辑（到什么条件平）。写下来，贴在屏幕旁。临场不改。

2. **盈亏比 ≥ 2:1 才做**。当前 1:173 倒挂意味着你的策略期望值为负——不改规则，再来 100 笔也是亏。

3. **跟单就跟到底**。要么完全跟（进场+离场全跟），要么纯自主但用死规则。跟单进场+恐慌离场=花钱买亏损。

4. **经济日历必看**。每月 NFP（非农）、CPI 前后 30min 不持仓或不加仓。这两个事件是波动放大器——你 7/2 黄金就是被 NFP 打爆的。

### 心态层

1. **恐慌=「我没计划」的信号，不是「该操作」的信号**。下次恐慌来时，先问自己：我的止损位到了吗？没到就不动。到了就执行，不需恐慌。

2. **接受小亏，拒绝大亏**。每笔止损控制在 2-3% 总资金，无条件执行。−2% 的止损是成本，−40% 的扛单才是灾难。

3. **赚 20-30 个点就跑不是错**——错的是没有事先定义。如果你开仓前就写了「+30pts 止盈」，到了就平，这是纪律。到了不平、跌回割肉，这是贪。

### 操作层（最快改进）

| 优先级 | 动作 | 效果 |
|--------|------|------|
| **立即** | 每单开仓即设止损单（交易所条件单，非心理止损） | 消除扛单可能性 |
| **立即** | 开仓前在纸上写「止损价____ 止盈逻辑____」 | 强迫规则先于情绪 |
| **本周** | 订阅经济日历提醒（NFP/CPI/FOMC） | 避免事件黑天鹅 |
| **本周** | 跟单=全跟，不自主干预离场 | 消除最差中间态 |
| **持续** | 盈亏比 <2:1 的单子不做 | 修复期望值倒挂 |

### 一句话

> **决策权该在计划手里，不在恐慌手里。** 你 10 笔交易里没有一笔有预设离场规则——这是所有亏损的根因。最快一步改进：**下一笔开仓的同时，下一张止损条件单。**
