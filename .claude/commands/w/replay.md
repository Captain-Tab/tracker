# /w:replay — 交易复盘

## 用户输入

```text
$ARGUMENTS
```

---

## 核心目的

把一笔或多笔交易记录复盘成**可执行的改进**，并落盘存档。不安慰、不结果论——用规则和数学说话。

**逻辑上分四个 Step 顺序执行，物理上一条命令跑完**：① 交易记录 → ② 分析 → ③ 复盘与总结 → ④ 建议 → ⑤ 落盘。唯一会停下来的点：Step 1 缺「离场原因」时追问。

---

## Step 1 · 交易记录（输入解析）

把输入解析成结构化记录。逐字段提取，**缺失标注「未提供」，不臆造**：

| 字段 | 说明 |
|------|------|
| 标的 / 方向 | 如 ETH / short |
| 开仓均价 / 杠杆 | |
| 离场均价 | 持仓中标注「持仓中」 |
| **离场原因** ⭐ | 规则触发 or 情绪/恐慌触发——诊断核心信号 |
| 结果 | 盈亏金额 + 收益率 |
| 当前价 / 现状 | 用于对照「若不离场会如何」 |
| 是否跟单 | 跟单 / 自主 / 跟单进场+自主离场（最差中间态）|

**硬规则**：离场原因缺失时**必须停下追问**，原因决定诊断方向。其余字段缺失可标注后继续。

输出：结构化表，逐笔列出。

---

## Step 2 · 分析（先算账，不照抄用户数字）

**必须实算核对**（用户收益率常含手续费/加仓误差）：

1. 价格变动 `(离场−开仓)/开仓` × 方向
2. 杠杆后收益率 = 价格变动 × 杠杆，与用户值对比，差额标注（手续费/加仓）
3. 爆仓距离 `±100%/杠杆`（让杠杆风险显形）
4. 多笔算**盈亏比** `Σ亏:Σ赚` + **不亏的胜率门槛** `亏/(亏+赚)`
5. 有当前价则算「若不离场现在盈亏」，对照实际离场点好坏（仅看清过程，**不得据此做结果论判断**）

输出：每笔实算过程 + 关键指标。

---

## Step 3 · 复盘与总结（诊断 + 认知纠正）

### 3.1 诊断清单（逐条核对，命中列证据）

| 维度 | 检查 |
|------|------|
| 盈亏比 | 是否倒挂？需多高胜率才不亏？ |
| 截断利润/让亏损奔跑 | 赚一点就跑、亏很多才动？ |
| 决策驱动源 | 规则驱动 or 情绪/恐慌驱动？恐慌常割在情绪峰值=最差点 |
| 止损/失效点 | 开仓前有无预设失效点？还是扛过纪律线+情绪峰值才割？ |
| 持有 vs 扛单 | 依据是「失效点未到」(持有✓) 还是「赌它回来」(扛单✗)？ |
| 杠杆 | 与把握脱节？爆仓距离过近？ |
| 跟单一致性 | 是否「跟单进场+自主情绪离场」最差中间态？ |

### 3.2 认知纠正（命中则对症引用）

- **结果论陷阱**：用「有无按规则」判断决策，不用价格事后走势。
- **止损是保费**：被洗是成本非错误；被洗多 = 该设**结构失效点**（阻力/前高外），非固定%。
- **持有 vs 扛单只差一个失效点**：没有失效点硬赌=扛单，期望值为负。
- **趋势看对 ≠ 该扛**：对的表达 = 轻仓+阻力位入场+结构止损。
- **跟单的离场是目标最值钱的判断**：自己情绪离场=拿最差能力换他最好能力。

输出：诊断（命中+证据）+ 认知纠正 + **一句话病根**。

---

## Step 4 · 建议（思维层 + 心态层 + 一句话）

**思维层**
1. 进场前先定离场：开仓即写死「止损价+止盈逻辑」，只执行不临场改。**没止损不开仓。**
2. 盈亏比 ≥ 2:1 才做。
3. 既然跟单就跟到底：要么完全跟（连离场），要么自主交易用死规则。别用「跟单进场+恐慌离场」。

**心态层**
1. 把「恐慌」踢出决策链：恐慌=信号告诉你「我没计划」，不是「该操作」。
2. 接受小亏拒绝大亏：止损设 2-3% 无条件执行。
3. 赚钱时拿得住：有离场计划，就不靠「怕」决定跑不跑。

**一句话**：用「决策权该在计划手里，不在恐慌手里」句式，收敛本次病根 + 最快一步改进。

## Step 5 · 落盘存档

把 Step 1–4 完整结果写入带日期的文档：

```bash
LOG_DIR="$(git rev-parse --show-toplevel 2>/dev/null || pwd)/.claude/pack/replay/log"
mkdir -p "$LOG_DIR"
TS=$(date +%Y-%m-%d-%H%M)
echo "写入：$LOG_DIR/replay-$TS.md"
```

- 文件路径：`.claude/pack/replay/log/replay-<YYYY-MM-DD-HHmm>.md`
- 文档首行 H1：`# 交易复盘 <YYYY-MM-DD HH:MM>`
- 正文 = Step 1–4 的四段完整输出（① 交易记录 / ② 分析 / ③ 复盘与总结 / ④ 建议）
- 写完向用户报告文件路径
