看板位置：当前项目 `.claude/kit/spec/cowork/<topic>.md`
- 不存在 → 先 `/k:cowork init` 建板
- 已存在 → 只更新你负责块的那一行 + append 日志，禁改别的块

写入：
1. 任务分解表——你这块填：会话名 / 分支 / status(doing|done|blocked)
2. 决策日志 append（禁改旧条目）：`[块ID] 敲定了什么 — 原因(尽量 file:line)`
3. 进度/坑——`[块ID] done: … | todo: …`；死路写「坑：试过 X 无效，因为…」
4. （仅当本会话调整了需求/底座）底座变更日志 append：`[今日日期] 改了什么 — 影响块: …`，并更新底座区「版本」为今日日期

写完只回一行：`已交接 → <看板路径>；新会话粘贴：@<路径> 然后 /k:cowork pickup`
