读协同看板续接工作，满血开局，不靠对话历史。

1. 找看板：当前项目 `.claude/kit/spec/cowork/` 下的看板文件；多个则列出让用户选 topic。
2. 全文吸收：底座区(目标/契约) + 决策日志 + 各块状态；底座细节看「spec 源」链接指向的全文。这是唯一信息源。
2.5 扫底座变更日志：若有「影响块」含你要接的块的条目 → 先确认这些后期变更已纳入再开工，防基于过期底座干活。
3. 认领一个块：
   - 用户指定了块ID → 接那个
   - 没指定 → 列出 status=todo / blocked 的块让用户选
   - 认领后在看板把该块 status 改 doing、填会话名
4. 命名对齐（消除随性命名，避免 bugfix / bugfix2 乱象）：
   - 工作分支统一 `fix/<topic>-<块ID>`（如 fix/airdrop-01-claim）
   - 已有偏离命名的分支，提示用户对齐
5. 按该块的 todo + 「下一步」开干。

只回一行确认：`已接 <块ID>，分支 <branch>，从「<下一步>」开始`
不复述看板全文。
