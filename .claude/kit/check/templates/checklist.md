## 📝 Git Commit 建议

按以下步骤输出，不得跳过：

**Step A：填写字段（仅英文）**

- type: `feat` / `fix` / `docs` / `style` / `refactor` / `perf` / `test` / `chore`
- scope: module name in English
- description: English verb phrase, ≤40 chars

**Step B：组合成一行命令**

```
git commit -m"<type>(<scope>): <description>"
```

**Step C：中文自检（必须执行）**

逐字扫描 Step B 的输出，是否含有任何中文字符（汉字）？
- 含有 → 重写 description 为英文，重新输出 Step B
- 不含 → 输出该行，流程结束

> 最终只输出这一行命令，无 bullet points，无多余文字。
>
> 正确示例：`git commit -m"fix(transfer): fix Spot-Perps token display logic"`
> 错误示例：`git commit -m"fix(transfer): 修复转账逻辑"` ← 含中文，必须重写
