# 评估体系盲区（watch-ready 假阳性）

> 2026-08-14 复核 sodex watchReady 推荐时发现。评估画像与真实状态存在系统性偏差，导致不合格地址被误判为 watch-ready。

## 背景

watchReady 判定只看「已平仓」的历史画像（`perps/positions` 的 realized_pnl 聚合），不看「当前持仓」的实时状态，也不识别交易者类型。复核发现本周 sodex 3 个 watchReady 全部为假阳性。

## 盲区 1：浮亏盲区

- **现象**：画像只看已平仓 realized_pnl，不看未平仓 unrealized_pnl。
- **案例**：`0x19781a809211e55491767f027c4de4183d60fe04`（ZHIPU+CL赚）——画像 PF ∞ / 100% 胜率，但当前 9 个空单净浮亏 **-$8,046**（占账户权益 28.5%），其中 MINIMAX 空单单笔浮亏 -$7,102。
- **根因**：metrics 只聚合 `perps/positions` 的 realized_pnl，未拉 `accounts/{addr}/state` 的 unrealized_pnl。
- **修复方向**：候选过滤时拉当前 state，加「净浮亏 / 账户权益 < X%」硬门槛（如 15%）。

## 盲区 2：做市商识别

- **现象**：做市/刷量机器人的交易特征被误判为「高频稳健型」交易者。
- **案例**：`0xf4e61f03d712dc32af52a1f922ffa73c7a619d12`（ZHIPU+MINIMAX赚）——40+ 品种杠杆配置、当前无持仓、185 笔/40 天、中位保证金 $12、PF 9.34。
- **识别指纹**：品种数 > 阈值（如 20）+ 无隔夜仓 + 中位保证金极小 + 异常高 PF（赚 spread 特征）。
- **修复方向**：按「品种数 + 持仓时长 + 中位保证金」三因子识别做市商，候选阶段剔除。

## 盲区 3：账户清空（离场）盲区

- **现象**：watchReady 结算时账户尚有资金/持仓，复核时 native + xyz 双账户全部 `av=$0`、无持仓，画像与当前资金完全脱节。
- **案例**：HYPE 本周 21 个 watchReady 中 5 个（`0x55b8…`/`0xbeaa…`/`0x1b2a…`/`0x1754…`/`0x1668…`）账户已归零。
- **根因**：watchReady 判定只看历史平仓画像，结算后不追踪账户是否清仓离场；「曾经赚钱」不等于「还在场」。
- **修复方向**：复核时拉 `clearinghouseState`，`av=$0` 且无持仓的直接剔除。

## 盲区 4：PF 异常（零亏损样本）盲区

- **现象**：PF ∞ 或极端值（141 / 208 / 23895）意味着亏损样本≈0，被评分体系当「稳赚」加分，实为小样本/全盈利造成的分母趋零爆炸。
- **案例**：`0x7ee9…` PF ∞（10 笔零亏损）、`0x55b8…` PF 23895、`0xd9f7…` PF 208。
- **根因**：metrics 直接 `总盈利 / 总亏损`，分母趋零时 PF 爆炸，未对样本数设下限、未对 PF 封顶。
- **修复方向**：PF 加 Laplace 平滑（`(sumWins+ε)/(sumLosses+ε)`），样本数 < N（如 20）时 PF 打折或降权，PF 设封顶（如 10）。

## 影响与关联

- sodex 本周 3 个 watchReady：2 个命中盲区 1/2，1 个为小账户（权益 $2.2K）。
- HYPE 本周 21 个 watchReady 复核：11 通过 / 8 假阳性（5 账户清空、2 浮亏爆仓、1 做市商）/ 2 存疑，假阳性率 ≈38%。
- 与 [[capped-truncation]]（nFills≥2000 截断失真）同属「画像与真实状态脱节」一类问题，建议统一在候选评估阶段补「实时 state 交叉验证」。
