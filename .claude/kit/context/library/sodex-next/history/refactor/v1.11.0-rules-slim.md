# v1.11.0 sodex-next UI rules 瘦身分类表

> **日期**: 2026-04-19
> **范围**: `rules/modules/sodex-next/` 5 个 UI rules
> **目的**: 消除与 `kit/projects/sodex-next/` 的重复内容,确立"红线 always-on + 详情按需加载"职责分层

---

## 背景

v1.10.0 建成 `kit/projects/` 按需加载机制,`/k:figma` 接入完成;但 UI 相关 rules(5 份,总 434 行)仍是 always-on 注入,与 `kit/projects/sodex-next/` 的 tokens.md / figma-mapping.md / components.md / patterns.md / constraints.md 内容 90%+ 重复。

本次瘦身将 rules 缩减为"硬约束红线",详情全部归档到 project。预计 token 节省 ~82%。
